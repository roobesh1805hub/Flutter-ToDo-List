# Flutter To-Do List Application

A simple and interactive To-Do List application developed using Flutter and Dart as part of my Flutter Development Internship at Auspify Technologies.

## Features

- Add, edit, and delete tasks
- Mark tasks as completed or pending
- Filter tasks by All, Pending, and Completed
- Track task completion with a dynamic progress bar
- Save tasks locally using SharedPreferences
- Restore saved tasks after restarting the application
- Clean and responsive Material Design interface

## Technologies Used

- Flutter
- Dart
- SharedPreferences
- Visual Studio Code

## How to Run

1. Install Flutter and configure the development environment.
2. Clone the repository.
3. Open the project directory.
4. Install dependencies using `flutter pub get`.
5. Run the application using `flutter run -d chrome`.

## Testing

Run `flutter analyze` to check for code issues and `flutter test` to execute automated tests.
